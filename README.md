# ANN

Deep learning pet projects, built one at a time to learn and master the topic.

## Layout
- `projects/` - one self-contained folder per project
- `common/` - small shared utilities (seeding, device selection)

## Setup
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
Run scripts from the repo root, e.g. `python -m projects.01_mlp_mnist.train`.
