# Dry Bean (UCI) - multiclass

- Source: https://archive.ics.uci.edu/dataset/602/dry+bean+dataset
- File: `dry_bean.csv` (13,611 rows, 16 numeric shape features), converted from the original `.xlsx`.
- Target: `Class`, 7 bean varieties (DERMASON 3,546 ... BOMBAY 522), so it's moderately imbalanced.
- Feature descriptions are in `description.txt`.
