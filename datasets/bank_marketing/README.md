# Bank Marketing (UCI)

- Source: https://archive.ics.uci.edu/dataset/222/bank+marketing
- Use `bank-additional/bank-additional-full.csv` (41,188 rows, `;` separated).
- Binary target: `y` (yes/no subscribed to a term deposit, about 11% yes).
- Don't use `duration` as a feature for a realistic model: it's only known after the call.
