# Default of Credit Card Clients (UCI, Taiwan) - binary

- Source: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
- File: `credit_card_default.csv` (30,000 rows, 25 columns), converted from the original `.xls`.
- Target: `default payment next month` (1 = default, about 22%).
- Features: credit limit, demographics, 6 months of repayment status (`PAY_*`), bill amounts (`BILL_AMT*`) and payments (`PAY_AMT*`).
